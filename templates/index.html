        About the model

        What it was trained on, how well it does, and where to be careful.

        Every prediction starts from {{ facts.inputs }} signals about a single visit: how many pages of each type were viewed, how long the visitor stayed on them, analytics measures such as bounce and exit rate, and context like visitor type and traffic source.

        A small neural network turns those signals into a probability that the session ends in a purchase. The page labels the session Purchase likely when that probability is above 50%.

        Read the score with care

        Only {{ facts.purchase_share }}% of the training sessions ended in a purchase, so a model that always answered "no purchase" would already be right {{ facts.baseline }}% of the time. Precision and recall say more than accuracy here: on sessions it had never seen, the model found about {{ facts.recall|round|int }} in 100 real purchases and was right about {{ facts.precision|round|int }} in 100 times it predicted one.

        The probability is the network's raw output and has not been calibrated. Operating system, browser, region and traffic type are anonymized codes in the dataset, so the form shows them as numbers rather than names. Inputs above anything in the training data are flagged in the result.
